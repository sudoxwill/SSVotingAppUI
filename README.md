# 📱 SS Voting App UI

A modern **Flutter UI concept for a TV show voting application**, inspired by the voting experience of **Secret Story Afrique**.

This project focuses primarily on **mobile UI/UX and Flutter implementation**, with the goal of exploring how a TV-show voting experience could be translated into a clean and engaging mobile application.

> ⚠️ **Disclaimer:** This is an independent UI concept created for learning and experimentation. It is not an official Secret Story Afrique application and is not affiliated with the show's producers or rights holders.

---

## ✨ Features

* 🎬 TV show inspired voting interface
* 👤 Contestant selection
* 🗳️ Voting-oriented user flows
* 📱 Mobile-first interface
* 🎨 Custom visual design and assets
* ⚡ Built with Flutter
* 🧩 Reusable Flutter widgets and components

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* [Flutter](https://flutter.dev/)
* Dart SDK
* Android Studio or another Flutter-compatible IDE

### Installation

Clone the repository:

```bash
git clone https://github.com/sudoxwill/SSVotingAppUI.git
```

Navigate to the project:

```bash
cd SSVotingAppUI
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
